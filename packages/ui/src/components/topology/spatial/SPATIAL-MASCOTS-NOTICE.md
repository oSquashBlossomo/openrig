# Spatial scene figures: notices

The spatial topology renderer draws two recognisable agent figures. Both are
built as geometry in code (`spatial-mascots.ts`). No third-party image, mesh,
texture or script is bundled.

## Clawd (Claude seats)

The body, arm, leg and eye dimensions are adapted from the engine definitions
(`DIM`, `LEGS`, eye placement) and the canonical palette of the **Claude Mascot
Style Gallery** (https://github.com/henrik-thevibe/Claude-Mascot-Style-Gallery),
an unofficial fan project, **not** an official Anthropic model. Only those
dimensions and colours were used; the gallery's canvas styles, scripts and

## Null (Codex seats)

The Null figure is a **volumetric reconstruction** made for OpenRig of
“Null” from **[“Codex Pets — Nine Pixel Companions” by Amit Sharma](https://www.figma.com/community/file/1673261581276170811/codex-pets-nine-pixel-companions)**,
licensed under
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).

Changes: the original is flat pixel art. Here it is reinterpreted as solid 3D
geometry (box head with a recessed face screen, raised orange NULL lettering,
a null-set chest emblem, torso, limbs and a curved tube antenna with a ring).
It is **not** an exported or official mesh, and no original asset file is
included.
